# Сайт «Семён · спецтехника из Китая»

Готовый статический сайт: 7 моделей из КП, сравнение, навесное, FAQ, форма заявки в WhatsApp.

## Как открыть

- Двойной клик по `index.html` — откроется в браузере, работает без сервера.
- Для проверки с телефона: в папке сайта выполнить `py -m http.server 8765`
  и открыть `http://<ip-компьютера>:8765`.

## Что где менять

| Что | Файл |
|---|---|
| Цены, характеристики, описания моделей | `app.js` → массив `MODELS` |
| Навесное (9 позиций) | `app.js` → массив `ATTACH` |
| Вопросы-ответы | `app.js` → массив `FAQ` |
| Телефон, ссылки WhatsApp/Telegram | `app.js` → `PHONE`, `WA`; `index.html` |
| Тексты секций, заголовки | `index.html` |
| Цвета, отступы, шрифты | `style.css` → блок `:root` |

### Добавить модель

1. Положить 1–3 фото в `img/`, имена вида `модель-1.jpg`.
2. Скопировать любой объект в `MODELS` и поправить поля:
   `id`, `name`, `type` (`loader` / `excavator`), `cls`, `tag`, `sub`, `price`,
   `short` (4 пары для карточки), `specs` (все характеристики), `desc`, `imgs`, `row` (для таблицы).
3. Сохранить — карточка, таблица, модалка и выпадающий список в форме обновятся сами.

### Поменять цену

В `MODELS` поле `price` — только число (например `390000`). Формат «390 000 ₽» подставится сам.
